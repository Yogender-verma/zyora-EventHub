# FestVerse 🎉

A modern and responsive college fest website developed as part of the **ZyoraByte Frontend Internship**.

## 📌 Project Overview

FestVerse is a college event website that allows users to:
- View upcoming events
- Check the fest schedule
- Explore guest speakers
- Register for events
- View a live countdown to the fest

## 🚀 Features

- Responsive Home Page
- Live Countdown Timer
- Event Schedule (Tabbed Layout)
- Speaker Cards
- Registration Form with Validation
- Local Storage for Registrations
